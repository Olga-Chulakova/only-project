# Only.digital Project

🏆 **Призёр чемпионата по вёрстке от HTML Academy** — проект занял **3 место** среди участников.

## 📌 Партнёры чемпионата
- Шрифт для проекта: https://typetype.ru/
- Дизайн, макет проекта: https://only.digital/
- Организатор: https://htmlacademy.ru/

## 📝 Описание

Одностраничный проект с полностью адаптивной, кроссбраузерной и «резиновой» вёрсткой с соблюдением семантики. Архитектура кода спроектирована для простоты поддержки и дальнейшего масштабирования. Работа получила высокую оценку экспертов за уровень технического исполнения.

## ⚙️🚀 Сборка и запуск - проект работает на последней версии node.js 22
- `npm ci`: устанавить зависимости;
- `npm start`: запуск версии для разработки;
- `npm run build`: сборка продакшн-версии;
- `npm run lint`: линтинг.
